# RenderTest 截帧工具 — 使用指引

适用游戏：《洛克王国：世界》（腾讯，UE5，D3D12，64位）

## 一、前期准备

编译环境：VS2022，工具集 v143，Release x64

需要的文件（从 `F:\renderdoc\src\x64\Release\` 获取）：
- `dxgi.dll` — proxy DLL，约 160KB
- `rendertest.dll` — RenderDoc 核心 DLL，约 25MB

截帧 UI 工具：
- `qrendertest.exe` — 位于 `F:\rdtest\`

## 二、部署步骤

游戏目录：`F:\洛克王国：世界(2002304)\Win64\NRC\Binaries\Win64\`

### 1. 编译（如果需要重新编译）

- VS2022 打开 `F:\renderdoc\src\renderdoc.sln`
- 选择 Release x64 配置
- 右键 renderdoc 项目 → 生成（输出 `rendertest.dll`）
- 右键 version_proxy 项目 → 生成（输出 `dxgi.dll`）

### 2. 部署

- 将 `dxgi.dll` 拷贝到游戏目录
- 将 `rendertest.dll` 拷贝到游戏目录
- 确保游戏目录下没有残留的 `dxgi.dll.tmp` 文件

### 3. 启动

- 通过游戏启动器正常启动游戏
- 打开 `F:\rdtest\qrendertest.exe`
- 在 Attach 列表中找到 `NRC-Win64-Shipping.exe`
- 确认 API 显示 **D3D12**
- 按 **F12** 截帧

### 4. 注意事项

- 每次游戏启动后，游戏目录下的 `dxgi.dll` 会被自动重命名为 `dxgi.dll.tmp`
- 下次启动前需要重新部署：
  - **方法A**：删除 `dxgi.dll.tmp`，重新拷贝 `dxgi.dll`
  - **方法B**：将 `dxgi.dll.tmp` 重命名回 `dxgi.dll`

## 三、一键部署脚本

在游戏目录下创建 `deploy.bat`：

```bat
@echo off
set SRC=F:\renderdoc\src\x64\Release
set DST=%~dp0
if exist "%DST%dxgi.dll.tmp" del "%DST%dxgi.dll.tmp"
copy /Y "%SRC%\dxgi.dll" "%DST%dxgi.dll"
copy /Y "%SRC%\rendertest.dll" "%DST%rendertest.dll"
echo Deploy complete.
pause
```

每次启动游戏前运行一次即可。

## 四、工作原理

**一句话总结**：在游戏目录放一个假的 `dxgi.dll`，游戏启动时会优先加载它而不是系统的，假 DLL 趁机把截帧工具塞进游戏进程，然后立刻把自己改名让反外挂找不到。

### 详细流程

1. 游戏通过 `LoadLibrary("dxgi.dll")` 加载我们的 proxy（游戏目录优先于 System32）
2. proxy DllMain 中：
   - 加载真正的 `System32\dxgi.dll` 和 `d3d12.dll`
   - 缓存真正函数指针
   - 将磁盘上 `dxgi.dll` 重命名为 `dxgi.dll.tmp`（绕过 ACE 文件名检测）
   - 修改 PEB 模块名为 `mfplat.dll`（绕过 ACE 模块枚举检测）
   - 加载 `rendertest.dll`（RenderDoc），安装 MinHook inline hook
3. 游戏后续调用 `CreateDXGIFactory2` / `D3D12CreateDevice` 时被 hook 拦截
4. RenderDoc 包装 DXGI Factory 和 D3D12 Device，截帧生效

## 五、故障排查

### API 显示 None

- 检查游戏目录下 `proxy.log`，确认所有 LoadLibrary 都显示 OK
- 确认 `proxy.log` 中有 `Init complete`
- 检查 `C:\Users\win11\AppData\Local\Temp\RenderTest\` 下是否有最新的 `RenderDoc_app_*.log`
- 日志中应有 `Inline hooked dxgi.dll!CreateDXGIFactory2` 和 `>>> CreateDXGIFactory2_hook ENTERED`

### ACE 弹窗"检测到非法劫持模块"

- 确认 `proxy.log` 中有 `Rename dxgi.dll -> dxgi.dll.tmp: OK`
- 如果重命名失败，可能是文件被占用或权限问题
- 确认游戏目录下没有残留的原始 `dxgi.dll` 文件

### 游戏无法启动 / 闪退

- 删除游戏目录下的 `dxgi.dll` 和 `dxgi.dll.tmp`
- 通过启动器修复游戏文件
- 重新部署

### 截帧后 qrendertest.exe 无法回放

- 确保 `qrendertest.exe` 以管理员权限运行
- 截帧文件保存在 `C:\Users\win11\AppData\Local\Temp\RenderTest\` 下
